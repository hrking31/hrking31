### 🚀 Featured projects

**🏪 Ferrequipos De La Costa** · *in production with a real client*\
Online store with kiosk mode, quotes, billing statements and accounts receivable with WhatsApp reminders. Business logic in Cloud Functions, tested with Vitest.\
`React` `Redux` `Material UI` `Firebase` `Cloud Functions` `Vitest` `PWA`\
[Live site](https://ferrequiposdelacosta.com) · [**Try the public demo, no sign-up**](https://mi-negocio-30949.web.app) · [Code](https://github.com/hrking31/ferrequiposdelacosta)

**📡 Alarma ITX** · *in production with a real client*\
8 ESP32 sensors with custom firmware sending data to Firebase in real time, with live charts and automatic Telegram alerts when a reading goes out of range.\
`React` `Tailwind CSS` `ESP32` `ESPHome` `Firebase` `Cloud Functions` `Recharts`\
[Live](https://alarmas-itx.web.app/) · [Code](https://github.com/hrking31/alarmas_itx) · [Firmware](https://github.com/hrking31/EspHomeRey)

**⛪ VoxDei** · *in production with a real client*\
Projects Bible verses, sermons and announcements on a TV, run from a separate control panel with sign-in, users and permissions.\
`React` `Vite` `Tailwind CSS` `Firebase` `Framer Motion`\
[Live](https://voxdei-ec499.web.app/) · [Code](https://github.com/hrking31/voxdei)

**📈 Demo Bolsa**\
REST API integration through my own Cloudflare Workers proxy: caching, rate-limit control, error handling, 66 automated tests and CI with GitHub Actions.\
`React` `Chart.js` `Cloudflare Workers` `Vitest` `GitHub Actions`\
[Live](https://demobolsa-31.web.app/) · [Code](https://github.com/hrking31/Demo-Bolsa)
